++++++++++++++++++
Telescope Position
++++++++++++++++++

TelescopePosition 플러그인은 망원경의 실시간 위치와 지령(대상) 위치를
표시합니다.

.. note:: 이 플러그인을 제대로 사용하려면 이러한 위치를 그리는 데 필요한
          상태를 제공하는 맞춤형 동반 플러그인을 작성해야 합니다. 그러한
          플러그인을 만들지 않았다면 망원경이 주차된 것처럼 보입니다.

망원경과 대상 위치는 적경/적위와 방위각/고도각 두 가지로 모두 표시됩니다.
RA와 DEC는 60진 표기법으로 RA는 HH:MM:SS.SSS, DEC는 DD:MM:SS.SS 형식으로
표시됩니다. AZ와 EL은 모두 소수 값의 도 단위로 표시됩니다. "Telescope"
섹션에는 포인팅이나 슬루 같은 망원경 상태가 슬루 시간(h:mm:ss)과 함께
표시됩니다.

"Plot telescope position" 옵션은 체크박스를 선택하면 Targets 창에 대상과
망원경 위치를 표시합니다.

"Target follow telescope" 옵션은 망원경이 어떤 대상에 "가까울" 때(가깝다는
것은 약 10분각 이내로 정의됨) Targets 플러그인 표에서 해당 대상이 선택되도록
합니다. 망원경 좌표에 실제로 가장 가까운 대상이 선택됩니다.

.. note:: 이 상자를 체크한 뒤 사용자가 수동으로 대상을 선택하면 옵션이
          자동으로 해제됩니다. 대상이 망원경을 다시 따르게 하려면 상자를
          다시 체크하기만 하면 됩니다.

"Pan to telescope position" 옵션은 TGTS 뷰어가 망원경 위치로 이동하도록
합니다. 많은 대상이 플롯되어 있고 극좌표 하늘 영역의 일부만 보이도록
확대했을 때 유용할 수 있습니다.

동반 플러그인 작성
==================

SPOT 소스 코드를 내려받아 "spot/examples" 폴더에서 "TelescopePosition_Companion"
이라는 플러그인 템플릿을 찾으세요. 템플릿에 설명된 대로 수정하면 됩니다.

+++++++++++
Target List
+++++++++++

Targets 플러그인은 보통 ``PolarSky`` 및 ``Visibility`` 플러그인과 함께 사용하여
관측할 수 있는 천체에 관한 정보를 표시합니다. 하나 이상의 대상 파일을 불러온
다음 "<wsname>_TGTS" 창에 플롯하거나, ``Visibility`` 플러그인 UI에서 가시성을
표시할 수 있습니다.

CSV 파일에서 대상 불러오기
==========================
대상은 "Name", "RA", "DEC", "Equinox"라는 열 제목을 담은 열 머리글이 있는
CSV 파일에서 불러올 수 있습니다(순서는 상관없습니다). 다른 열이 있어도 되지만
무시됩니다. 이 형식에서 RA와 DEC는 소수 값(이 경우 도로 해석됨) 또는 60진
표기법(RA는 HH:MM:SS.SSS, DEC는 DD:MM:SS.SS)으로 지정할 수 있습니다. Equinox는
예를 들어 J2000 또는 2000.0으로 지정할 수 있습니다.

.. note:: SPOT은 "SOSS 표기법"으로 된 CSV 파일에서도 대상을 읽을 수 있습니다.
          OPE 파일에서 대상을 불러오는 아래 섹션을 참조하세요.

플롯할 대상에 특정 색상을 지정하려면 파일을 열기 전에 "Color" 버튼을 클릭하여
색상을 직접 선택하세요. 그렇지 않으면 (아래에서 더 설명하는) "Rotate target
colors" 옵션에 따라 대상 색상이 지정됩니다.

"File" 버튼을 누르고 위 형식의 CSV 파일로 이동하여 선택합니다. 또는 "File"
버튼 옆 상자에 파일 경로를 입력하고 "Set"을 누릅니다(후자의 방법은 편집한
파일을 빠르게 다시 불러오는 데에도 사용할 수 있습니다).

대상이 표에 채워집니다.

OPE 파일에서 대상 불러오기
==========================
OPE 파일은 스바루 망원경에서 사용하는 특수한 형식의 파일입니다. 이런
종류의 파일에서 대상은 "SOSS 표기법"(RA는 HHMMSS.SSS, DEC는 +|-DDMMSS.SS,
Equinox는 NNNN.0)으로 지정됩니다.

CSV 파일에서 대상을 불러오는 위 지침을 따르되, 대신 OPE 파일을 선택하세요.

.. note:: 이 형식을 불러오려면 선택적 "oscript" 패키지를 설치해야 합니다:
          (pip install git+https://github.com/naojsoft/oscript).

PRM 파일 업로드
===============
OPE 파일은 별도의 "PRM" 파일에 정의된 대상을 참조하는 경우가 많습니다. CSV나
OPE 파일과 같은 방식으로 ``.prm`` 파일을 선택(또는 끌어다 놓기)하세요. 이
파일은 대상을 불러오는 대신 ``~/.spot/prm`` 에 저장(및 유지)되어, 이후에
불러오는 OPE 파일이 참조하는 대상을 해석할 수 있게 합니다.

표 정보
=======
대상 표는 대상에 관한 정보를 요약합니다. 대상 이름, RA, DEC 같은 정적 정보용
열과, 방위각, 고도, 색상으로 구분된 출/몰 아이콘, 시간각, 대기질량, 대기
분산, 시차각, 달 이격 같은 동적으로 갱신되는 정보용 열이 있습니다.

조작
====
대상을 "태그"하려면 목록에서 하나 이상의 대상을 선택하고 "Tag"를 누릅니다.
어느 대상이 태그되었는지 보여주기 위해 "Tagged" 열 아래 왼쪽에 체크 표시가
나타납니다. 대상의 태그를 해제하려면 목록에서 태그된 대상을 하나 이상
선택하고 "Untag"를 누릅니다.

`<wsname>_TGTS` 창에서 대상은 SiteSelector 플러그인에 설정된 시각의 위치에
플롯됩니다. 대상이 태그된 경우 색상은 마젠타 계열이 됩니다. 대상이 선택되면
파란색으로 나타나고, `<wsname>_TGTS` 창에서 이름은 빨간색 테두리의 흰색
배경을 갖습니다. 그렇지 않으면 대상은 해당 대상이 담긴 파일을 불러올 때
수동 또는 자동으로 선택된 색상에 따라 표시됩니다.

"Select All" 버튼은 표의 모든 대상을 선택합니다.

대상을 선택하고 "Delete"를 누르면 선택한 대상이 목록에서 제거됩니다. 범주
행만 선택된 경우(대상은 선택되지 않음) 이 버튼을 누르면 해당 범주의 모든
대상이 삭제됩니다.

대상 하나를 선택한 뒤 "Browse"를 클릭하면 좌표로 대상을 조회하고 결과를 웹
브라우저에 표시하는 옵션 메뉴가 열립니다.

"Plot:" 옆의 드롭다운 메뉴는 `<wsname>_TGTS` 창에 어떤 대상이 플롯되는지를
변경합니다. "All"을 선택하면 모든 대상을 표시하고, "Uncollapsed"를 선택하면
표에서 접히지(숨겨지지) 않은 대상과 태그 및 선택된 대상을 표시하며,
"Tagged+Selected"를 선택하면 태그되었거나 선택된 모든 대상을 표시하고,
"Selected"를 선택하면 선택된 대상만 표시합니다.

설정 메뉴
=========
"Settings" 버튼을 클릭하면 특정 설정을 활성화하는 팝업 메뉴가 나타납니다.

* "Merge Targets"를 체크하면 *그 이후에* 불러오는 모든 대상이 파일 이름별로
  묶이는 대신 "Targets"라는 하나의 제목 아래에 정리됩니다.
* "List Unreferenced Targets"는 OPE 파일에만 영향을 주는 설정입니다. 보통
  Targets 플러그인은 명령에서 참조되지 않는 대상을 무시합니다. 이 설정을
  체크하면 참조 여부와 관계없이 모든 대상을 표시합니다. 이는 PRM 포함
  파일의 대상을 표시하는 데 사용할 수 있습니다.
* "Plot solar system objects" 옵션을 체크하면 `<wsname>_TGTS` 창에 태양,
  지구의 달, 행성, 명왕성을 플롯합니다.

* "Rotate target colors" 옵션은 불러오는 각 파일이 대상에 대해 서로 다른
  자동 선택 색상을 사용하도록 합니다(이는 "Merge targets"가 꺼져 있을 때만
  적용됩니다).
* "Enable DateTime setting"은 CSV 파일에 "DateTime" 열이 포함된 경우 고정
  날짜/시각 설정을 활성화하는 옵션입니다. 활성화하면 표에서 대상 하나를
  선택할 때 SiteSelector 플러그인의 날짜/시각이 해당 날짜와 시각으로
  설정됩니다. 이 열의 형식은 YYYY-MM-DD HH:MM:SS <TZ> 여야 합니다. 표준
  시간대 문자열을 생략하면 UTC로 간주됩니다.

PolarSky
========
PolarSky disegna un grafico polare nella finestra "<wsname>_TGTS", si occupa
di tracciarvi gli oggetti e mostra anche una piccola finestra con le
informazioni dell'almanacco astronomico (tramonto/sorgere del Sole,
tramonto/sorgere della Luna, crepuscoli, ecc.).

Poiché le guide del grafico polare sono utili per interpretare i tracciati
dei target, ecc., di solito vorrai avviare questo plugin se prevedi di usare
anche i plugin ``Targets`` o ``Visibility``. Se non sei interessato alle
informazioni dell'almanacco, puoi ridurre a icona l'interfaccia del plugin
dopo averlo avviato.

PolarSky
========
PolarSky dibuja un gráfico polar en la ventana "<wsname>_TGTS", se encarga de
trazar objetos en ella y también muestra una pequeña ventana con información
de almanaque astronómico (orto/ocaso del Sol, orto/ocaso de la Luna,
crepúsculos, etc.).

Como las guías del gráfico polar son útiles para interpretar los trazados de
objetivos, etc., normalmente querrá iniciar este complemento si tiene
previsto usar también los complementos ``Targets`` o ``Visibility``. Si no le
interesa la información del almanaque, puede minimizar la interfaz del
complemento tras iniciarlo.

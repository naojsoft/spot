CPanel
======
CPanel 是 SPOT 应用程序的控制面板（Control Panel）。

使用 CPanel 可以启动新的工作区，或在特定工作区中打开 SPOT 规划插件。

创建工作区
----------
要打开工作区，请从可编辑的下拉框中选择一个（其中会填入在
``$HOME/.spot/workspaces`` 中找到的工作区），或在其中输入一个新名称，然后
按其右侧的 “Open Workspace” 按钮。工作区名称必须唯一。如果将该框留空，则会
以通用名称创建一个工作区。

选择已打开工作区的选项卡，以查看并操作将在该处打开的插件。

选择用于启动插件的工作区
------------------------
使用 “Select Workspace” 下拉菜单，选择要在其中启动某个 SPOT 规划插件的已
打开工作区（注意必须先用 “Open Workspace” 打开该工作区）。然后使用下面的
复选框来启动（勾选）或停止（取消勾选）插件。

你几乎总是会想启动 “SiteSelector” 插件，因为它控制着工作区上其他插件的许多
方面。

提示：最小化插件
----------------
有时你想启动某个插件以使用它的部分功能，但可能并不关心查看该插件的界面
（“SiteSelector”、“PolarSky” 和 “SkyCam” 插件就是很好的例子）。在这种情况
下，你可以启动插件，然后单击插件界面标题栏中的界面最小化按钮，将插件最小化
以便为其他插件腾出空间。

.. important:: 关闭某些插件可能导致其他插件无法按预期工作。例如，
               SiteSelector 插件作为几乎所有其他插件的时间更新来源非常
               重要，如果将其完全关闭，那里的时间跟踪器可能不再触发那些
               其他插件的更新。如有疑问，请将插件最小化而不是关闭。

保存工作区布局
--------------
按下 “Save <wsname> layout” 按钮，即可保存你在该工作区中打开的插件窗口的
当前大小和位置，以及当前正在运行的插件。每个工作区的布局都会单独保存在
``$HOME/.spot/workspaces/<wsname>/workspace.json`` 中。

下次启动 SPOT 并打开同名工作区时，它将以保存的大小和位置重新创建这些窗口，
并重新启动保存时正在运行的插件。

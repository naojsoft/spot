+++++++++++
Target List
+++++++++++

Targets 插件通常与 ``PolarSky`` 和 ``Visibility`` 插件配合使用，以显示有关
可观测天体的信息。它允许你加载一个或多个目标文件，然后将它们绘制在
“<wsname>_TGTS” 窗口中，或在 ``Visibility`` 插件界面中显示它们的可见性。

从 CSV 文件加载目标
===================
可以从包含列标题 “Name”、“RA”、“DEC” 和 “Equinox” 的表头的 CSV 文件加载
目标（它们不必按该顺序排列）。可以存在其他列，但会被忽略。在此格式中，RA 和
DEC 可以指定为十进制值（此时被解释为度）或六十进制表示法（RA 为
HH:MM:SS.SSS，DEC 为 DD:MM:SS.SS）。Equinox 可以指定为例如 J2000 或 2000.0。

.. note:: SPOT 也可以从采用 “SOSS 表示法” 的 CSV 文件读取目标。请参阅下面
          关于从 OPE 文件加载目标的部分。

如果你想为要绘制的目标设置特定颜色，请在继续打开文件之前单击 “Color” 按钮
手动选择颜色，否则将根据（下面进一步描述的）名为 “Rotate target colors” 的
选项为目标着色。

按下 “File” 按钮，导航到并选择一个符合上述格式的 CSV 文件。或者，在 “File”
按钮旁边的框中输入文件路径并按 “Set”（后一种方法也可用于快速重新加载你已
编辑过的文件）。

目标应会填入表格。

从 OPE 文件加载目标
===================
OPE 文件是斯巴鲁望远镜使用的一种特殊格式的文件。这类文件中的目标以 “SOSS
表示法” 指定（RA 为 HHMMSS.SSS，DEC 为 +|-DDMMSS.SS，Equinox 为 NNNN.0）。

按照上面从 CSV 文件加载目标的说明操作，但改为选择一个 OPE 文件。

.. note:: 为了加载此格式，你需要安装可选的 “oscript” 软件包：
          (pip install git+https://github.com/naojsoft/oscript)。

上传 PRM 文件
=============
OPE 文件常常引用在单独的 “PRM” 文件中定义的目标。像处理 CSV 或 OPE 文件
那样选择（或拖放）一个 ``.prm`` 文件：它不会加载目标，而是被保存到
``~/.spot/prm`` 中（并持久化），以便随后加载的 OPE 文件能够解析它们所引用
的目标。

表格信息
========
目标表汇总了有关目标的信息。其中有用于静态信息（如目标名称、RA、DEC）的列，
以及用于动态更新信息（方位角、高度、彩色编码的升/落图标、时角、大气质量、
大气色散、视差角和月亮角距）的列。

操作
====
要“标记”目标，请在列表中选择一个或多个目标并按 “Tag”。“Tagged” 列下方的
左侧将出现一个对勾，以显示哪些目标已被标记。要取消标记某个目标，请在列表中
选择一个或多个已标记的目标并按 “Untag”。

在 `<wsname>_TGTS` 窗口中，目标将绘制在 SiteSelector 插件所设定时间对应的
位置。如果目标已被标记，其颜色将为品红色系。如果某个目标被选中，它将显示为
蓝色，并且在 `<wsname>_TGTS` 窗口中其名称将带有白色背景和红色边框。否则，
目标将根据加载包含这些目标的文件时手动或自动选择的颜色着色。

“Select All” 按钮将选择表格中的所有目标。

选择目标并按 “Delete” 将从列表中移除所选目标。如果只选中了一个类别行（但没有
选中目标），按此按钮将删除该类别中的所有目标。

选择单个目标然后单击 “Browse”，将打开一个选项菜单，用于按坐标查找该目标并
在 Web 浏览器中显示结果。

“Plot:” 旁边的下拉菜单会更改在 `<wsname>_TGTS` 窗口中绘制哪些目标。选择
“All” 将显示所有目标，选择 “Uncollapsed” 将显示表格中未折叠（隐藏）的所有
目标以及已标记和选中的目标，选择 “Tagged+Selected” 将显示所有已标记或被
选中的目标，选择 “Selected” 将仅显示被选中的目标。

设置菜单
========
单击 “Settings” 按钮将弹出一个菜单，用于启用某些设置。

* 如果你勾选 “Merge Targets”，则*此后*加载的所有目标都将归入 “Targets” 这
  一个标题之下，而不是按文件名分组。
* “List Unreferenced Targets” 是一个只影响 OPE 文件的设置。通常，Targets
  插件会忽略在命令中未被引用的目标。勾选此设置将显示所有目标，无论它们
  是否被引用。这可用于显示 PRM 包含文件中的目标。
* 勾选 “Plot solar system objects” 选项将在 `<wsname>_TGTS` 窗口中绘制太阳、
  地球的月亮、各行星以及冥王星。

* “Rotate target colors” 选项意味着每个加载的文件都将为其目标使用一种不同
  的自动选择颜色（仅当 “Merge targets” 关闭时才会生效）。
* “Enable DateTime setting” 是一个选项，当 CSV 文件包含 “DateTime” 列时，
  用于启用固定日期/时间的设置。启用后，在表格中选择单个目标会将 SiteSelector
  插件中的日期/时间设置为该日期和时间。此列的格式应为：
  YYYY-MM-DD HH:MM:SS <TZ>。如果省略时区字符串，则假定为 UTC。

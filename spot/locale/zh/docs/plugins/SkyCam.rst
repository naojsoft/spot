++++++++
Sky Cams
++++++++

SkyCam 插件用于在 Targets 通道的背景上放置全天相机图像，以帮助监测天空状况。
有一个下拉菜单可供从多个站点中选择。

设置天空图像
============

从 “全天相机” 下的下拉菜单中选择你想使用的相机服务器。然后，勾选
“显示天空图像” 旁边的复选框，以在 `<wsname>_TGTS` 窗口中显示图像。天空
图像可能需要片刻才会出现。图像更新时，最后一幅图像的日期和时间会显示在窗口
底部的 “图像下载信息” 下方。

有些全天相机生成彩色图像。勾选 “单色” 复选框可将其转换为单色（灰度）
图像；取消勾选则显示原始颜色。

天空图像使用查看器的色图和截断水平绘制，因此你可以用常规的查看器控件调整其
对比度和截断水平（彩色图像只适用截断水平）。新图像到达时，你的设置会被保留。

差分图像
========

勾选 “显示差分图像” 旁边的复选框，即可显示相机最近两幅图像之间
天空的变化，而不是图像本身。这使移动或发展中的云更容易被看到。在默认的
“灰色” 色图中，没有变化的区域为中灰色，变亮的区域更亮，变暗的区域更暗。被月光
或城市灯光照亮的云通常会变亮；遮挡星星或银河的云则会变暗。

为生成差分图像，两幅图像都会被转换为单色、降低分辨率并进行中值滤波，从而去除
大部分星星和噪声。前一幅图像会按当前图像的整体亮度进行缩放，这样相机曝光的
变化就不会看起来像云。然后将差值除以图像噪声的估计值，因此差分图像以噪声
（“sigma”）为单位。

各控件如下：

* “补偿天空旋转”：天空每分钟约旋转四分之一度，因此星星在图像之间会移动。
  勾选此项后，前一幅图像会绕天极旋转到当前图像的时刻，使星星相互抵消，只留下
  真实的变化。这要求 skycams.yml 中相机的朝向正确（参见“添加新相机”）。
  固定在相机视野中的物体，例如地平线附近的圆顶或树木，可能会留下弯曲的条纹。

* “阈值”：在计算云量时，大于此 sigma 数的变化被视为云（默认值 5）。

* “色图”：差分图像的色图。“灰色” 和 “变化量”（只显示变化的大小，
  不区分变亮还是变暗）能让目标叠加层保持易读；“青/琥珀” 和 “蓝/红”
  用颜色显示变化的方向。

* “云量”：天顶 75 度以内的天空中，变化超过阈值的部分所占的百分比。
  它测量的是在图像之间移动或变化的云；不发生变化的均匀阴天不会显示出来。
  当相机所在地的太阳高于地平线下 12 度时，天空亮度变化太快，该值没有意义，
  因此会改为显示 “晨昏蒙影” 或 “白天”。

差分图像有自己的色图和截断水平（默认为 -10 到 +10 sigma），与普通图像的
相互独立，你同样可以用常规的查看器控件调整它们。

选择相机后，收到第二幅图像时差分图像才会出现。如果下载得到的图像与上一幅相同
（相机尚未更新），该图像会被忽略。

“保存配置” 按钮会为工作区记录你当前的选择（相机服务器、“显示天空图像”、“显示差分图像” 和 “单色”），以便下次打开时恢复。

添加新相机
==========

如果你有可以通过 Web 协议获取的合适图像源，就可以轻松添加你自己的全天相机
图像。如果你已检出 SPOT 源代码，可以在 .../spot/spot/config/ 中找到文件
“skycams.yml”。将此文件复制到 $HOME/.spot 并编辑它以添加你自己的相机。你
需要提供用于下载图像的 URL、标题、图像中表示天顶的中心像素（X 和 Y 坐标）、
到地平线的圆的半径（像素）、要应用的旋转、是否在 X 或 Y 方向翻转图像，以及
以秒为单位的更新间隔。你还可以用 “latitude”（南半球为负值）和 “longitude”
（格林尼治以西为负值）给出相机的位置（单位为度）。纬度用于在差分图像中补偿
天空的旋转，纬度和经度一起用于判断相机所在地是否为夜间。如果不指定，则使用
SPOT 中所选站点的位置，而当相机位于其他站点时这是不正确的。

有些相机只发布动画图像（例如最近若干幅图像的 GIF 循环）。此时 SPOT 使用动画
的最后一帧，它通常是最新的图像；如需使用其他帧，请用 “frame” 给出其编号（从
0 开始计数，或用 -1 表示最后一帧）。

旋转和翻转必须使图像北在上、东在左，与极坐标天空图相同（南北半球都一样）。
一个好的检查方法是：天空图像中的月亮或亮行星与其在 SPOT 中的位置一致，并且
在勾选 “补偿天空旋转” 的差分图像中星星会相互抵消。

重新启动 spot 后，你应该就能从列表中选择你的新相机了。

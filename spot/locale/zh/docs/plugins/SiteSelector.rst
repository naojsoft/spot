SiteSelector
============
SiteSelector 插件用于选择你计划进行观测的地点，以及在该地点的观测时间。

你几乎总是会想先启动本插件，因为它控制着工作区上其他插件的许多方面。

设置观测地点
------------
使用 “Site:” 下拉菜单选择观测地点。其中提供了若干预定义的站点。

添加你自己的自定义观测地点
--------------------------
如果没有你想要的地点，你可以轻松地自行添加。如果你检出了 SPOT 源代码，可以
在 .../spot/spot/config/ 中找到文件 “sites.yml”。将此文件复制到 $HOME/.spot
并编辑它以添加你自己的站点。务必设置站点的所有关键字（纬度、经度、海拔
等）。重启 spot，你应该就能看到新的地点了。

设置观测时间
------------
时间可以设置为当前时间或固定时间。要设置为当前时间，请从 “Time mode:”
下拉菜单中选择 “Now”。

要设置固定时间，请选择 “Fixed”——这将启用 “Date time:” 和 “UTC offset
(min):” 控件。在第一个框中以 YYYY-MM-DD HH:MM:SS 的格式输入日期/时间，然后
按 “Set”。

默认情况下，固定时间的 UTC 偏移将设置为观测地点所在时区的偏移；但你可以在
另一个框中输入自定义的相对 UTC 偏移（以*分钟*为单位）并按 “Set”，以指定解释
该时间所用的特殊偏移。

.. note:: 这并不会更改观测地点的时区；它只是设置你所设定的固定时间的解释
          方式。

插件的更新
----------
每当你更改观测地点或时间时，其他插件应会自动更新（前提是它们订阅了站点和
时间变更，大多数插件都是这样设计的）。

.. important:: 关闭本插件可能导致其他插件无法按预期工作。SiteSelector 作为
               几乎所有其他插件的时间更新来源非常重要，如果将其完全关闭，
               那里的时间跟踪器将不再触发那些其他插件的更新。如有疑问，请
               启动并最小化本插件，而不是关闭它。

++++++++++++++++
Target Generator
++++++++++++++++

TargetGenerator 允许你以多种方式之一动态生成目标。随后可将该目标添加到
“Targets” 插件表中。

.. note:: 请确保同时打开 “Targets” 插件，因为它需要与本插件配合使用。

从方位角/高度角生成目标
=======================

只需在 “方位角:” 框中输入方位角，在 “高度角:” 框中输入高度角。单击 “生成目标”，
即可使用站点的设定时间将 AZ/EL 坐标转换为 RA/DEC 坐标。这将填充下一节中的
“赤经”、“赤纬”、“分点” 和 “名称” 框。之后你可以按下一节所述添加该目标。

从已知坐标生成目标
==================

如果已知 RA/DEC 坐标，可以将它们输入到标有 “赤经”、“赤纬”、“分点” 和 “名称”
的框中。这些值可以用六十进制表示法或度给出。

.. note:: 如果你安装了 “oscript” 软件包，也可以使用 “SOSS 表示法”。

单击 “添加目标” 以添加目标。它将出现在 “Targets” 插件的目标表中。在那里
按通常方式选择它，即可在 “PolarSky” 或 “Visibility” 图中查看它。

从名称服务器查找目标
====================

可以使用第三个区域中的控件，通过名称服务器（NED 或 SIMBAD）查找目标。只需
从标有 “服务器” 的下拉框中选择你的名称服务器，在 “名称” 框中输入名称，然后
单击 “搜索名称”。如果找到该天体，它将填充第二节中标有 “赤经”、“赤纬”、
“分点” 和 “名称” 的框。之后你可以单击 “添加目标” 按钮来添加该目标。

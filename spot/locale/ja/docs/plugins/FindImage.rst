FindImage
=========
FindImage プラグインは、既知の座標について画像カタログから画像をダウンロード
して表示するために使います。見つかった画像の表示には「{wsname}_FIND」ビューア
を使用します。

.. note:: このプラグインは「Targets」プラグインと組み合わせて使うため、
          「Targets」プラグインも開いておいてください。

ターゲットの選択
----------------
「Targets」プラグインで、ターゲットを 1 つだけ選択して一意に指定します。
次に FindImage の「指向」領域にある「選択を取得」ボタンをクリックします。
これにより「赤経」「赤緯」「分点」「名前」フィールドが入力されます。

.. note:: 望遠鏡ステータス連携が動作している場合は、「望遠鏡を追従」
          チェックボックスをクリックすると、望遠鏡の実際の位置が Targets
          プラグインに読み込まれたターゲットと一致するときに、その位置で
          「指向」領域が更新されます。さらに、find ビューアの画像が
          望遠鏡の現在位置に応じてダウンロードされ、パンされるため、
          （例えば）ディザリングパターンを追うことができます。

画像ソースからの画像の読み込み
------------------------------
「指向」領域に RA/DEC 座標が表示されたら、「画像ソース」領域の
コントロールを使って画像をダウンロードできます。「ソース」ドロップダウン
コントロールから画像ソースを選び、「サイズ（分角）」コントロールでサイズ（分角）を
選択して「画像を検索」ボタンをクリックします。画像がダウンロードされて
find ビューアに表示されるまで、少し時間がかかることがあります。

.. note:: 代わりに、「FITSを読み込む」でその領域の有効な WCS を持つローカルの
          FITS ファイルを読み込むことも、「空の画像を作成」で目的の位置に WCS
          を設定した空の画像を作成することもできます。画像ソースをダウンロード
          で利用できない場合、これらが役立つことがあります。

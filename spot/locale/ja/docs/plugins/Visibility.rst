+++++++++++++++
Visibility Plot
+++++++++++++++

このウィンドウには、ターゲットリストで選択したターゲットの高度の時間変化を
示す表示が含まれます。

.. note:: ターゲットが 1 つも選択されていない場合、このウィンドウは空になり
          ます。

強調表示された領域
==================

上下の黄色の領域は警告領域です。これらの領域では、エアマスが大きい、または
高度が非常に高いため、観測が困難です。赤い破線の縦線はサイトの日没時刻と
日の出時刻です。縦のオレンジの領域は常用薄明の時間帯を、縦のラベンダーの
領域は航海薄明の時間帯を、縦の青の領域は天文薄明の時間帯を示します。緑の
領域は現在時刻から次の 1 時間を示します。

プロット範囲の設定
==================

プロットする時間間隔を変更するには、「時間軸:」と表示されたボタンを押して
ドロップダウンメニューを開きます。Night Center、Day Center、Current の 3 つの
オプションがあります。「夜の中心」は時間軸を夜の中心（:doc:`polarsky`
ウィンドウで確認できます）に合わせます。時間軸は日没の少し前から日の出の
少し後までになります。「昼の中心」は時間軸を昼の中心に合わせ、時間軸は
日の出から日没までになります。「現在」は時間軸をおよそ -2 から +7 時間に
設定し、時間の経過に応じて自動的に調整されます。

ターゲットの選択
================

「プロット:」の隣のドロップダウンメニューで、可視性プロットにどのターゲットを
プロットするかを制御します。「すべて」を選ぶとすべてのターゲットが表示され、
「展開中」を選ぶと、ターゲット表で折りたたまれて（隠されて）いない
ターゲットに加えて、タグ付きおよび選択済みのターゲットが表示されます。
「タグ付き+選択済み」を選ぶとタグ付きまたは選択済みのすべてのターゲットが
表示され、「選択済み」を選ぶと選択済みのターゲットのみが表示されます。

設定メニュー
============
「設定」ボタンをクリックすると、いくつかの設定を有効にするためのポップ
アップメニューが表示されます。

* Plot moon separation。このオプションをチェックすると、天体が地平線より上に
  ある間、各プロット線に沿って 1 時間ごとに月との離角が度で表示されます。
* Plot polar Az/El。このオプションをチェックすると、時間軸に選択された期間
  （上記参照）における各ターゲットの位置を示す線が、プロットのターゲット選択
  で選ばれたターゲットについて「<wsname>_TGTS」ビューアに作成されます。これに
  より、SiteSelector の時刻に応じたターゲット位置だけでなく、それ以上のことを
  確認できます。

++++++++++++++
Instrument FOV
++++++++++++++

InsFov プラグインは、`<wsname>_FIND` ウィンドウのサーベイ画像の上に観測装置の
視野（FOV）を重ねて表示します。

.. note:: このプラグインが正しく動作するには、あらかじめ（「FindImage」
          プラグインを使って）正確な WCS を持つ画像を find ビューアに
          ダウンロードしておくことが重要です。

観測装置の選択
==============

観測装置は、「Instrument」の下の「Choose」ボタンを押し、目的の観測装置が
見つかるまでメニューをたどることで選択できます。観測装置を選択すると、
その名前が「Instrument:」に表示され、観測装置の視野の輪郭が
`<wsname>_FIND` ウィンドウに現れます。

位置角を調整でき、それに応じて画像上の観測装置 FOV オーバーレイの角度が
変わります。「Rotate w/PA」ボックスをチェックすると、FOV オーバーレイの
向きが保たれるようにビューア画像が回転します。

赤経・赤緯は、`<wsname>_FIND` ウィンドウでパン位置を設定すると（例えば
Shift クリックで）自動的に入力されますが、座標を入力して手動で調整すること
もできます。赤経・赤緯は小数値（度）または 60 進表記で指定できます。

現在の望遠鏡の指向に画像を合わせるには、``FindImage`` プラグインの UI で
「Follow telescope」の隣のボックスをチェックします。find 画像の WCS が
十分に正確であれば、空のある領域でディザリングが行われる様子を観察できます。

.. note:: 「Follow telescope」機能を動作させるには、TelescopePosition
          プラグインのドキュメントで説明されているように、望遠鏡から
          ステータスを取得するコンパニオンプラグインを書いておく必要が
          あります。

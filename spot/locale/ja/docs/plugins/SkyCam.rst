++++++++
Sky Cams
++++++++

SkyCam プラグインは、Targets チャンネルの背景に全天カメラの画像を表示し、空の
状態の監視を助けます。いくつかのサイトから選べるドロップダウンメニューがあり
ます。

全天画像の設定
==============

「All Sky Camera」の下のドロップダウンメニューから使用したいカメラサーバーを
選択します。次に「Show Sky Image」の隣のチェックボックスを押すと、
`<wsname>_TGTS` ウィンドウに画像が表示されます。全天画像が現れるまで少し時間が
かかることがあります。画像が更新されると、最後の画像の日時がウィンドウ下部の
「Image Download Info」の下に表示されます。

SkyCam プラグインは、「Show Differential Image」の隣のチェックボックスを選択
することで、選択したチャンネルサーバーから差分画像を生成することもできます。

新しいカメラの追加
==================

Web プロトコルで取得できる適切な画像フィードがあれば、独自の全天カメラ画像を
簡単に追加できます。SPOT のソースコードをチェックアウトしている場合は、
.../spot/spot/config/ に「skycams.yml」というファイルがあります。このファイル
を $HOME/.spot にコピーし、編集して独自のカメラを追加してください。画像を
ダウンロードする URL、タイトル、天頂を表す中心ピクセル（X・Y 座標）、地平線
までの円の半径（ピクセル）、適用する回転、画像を X 方向・Y 方向に反転するか
どうか、そして秒単位の更新間隔を指定する必要があります。

spot を再起動すると、一覧から新しいカメラを選べるようになります。

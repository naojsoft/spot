+++++++++++
Target List
+++++++++++

Targets プラグインは、通常 ``PolarSky`` および ``Visibility`` プラグインと
組み合わせて使い、観測できる天体に関する情報を表示します。1 つ以上の
ターゲットファイルを読み込み、それらを「<wsname>_TGTS」ウィンドウにプロット
したり、``Visibility`` プラグインの UI で可視性を表示したりできます。

CSV ファイルからのターゲット読み込み
=====================================
ターゲットは、列見出しに「Name」「RA」「DEC」「Equinox」という列タイトルを
含む CSV ファイルから読み込めます（順序は問いません）。他の列があっても
かまいませんが、無視されます。この形式では、RA と DEC は小数値（この場合は
度として解釈されます）または 60 進表記（RA は HH:MM:SS.SSS、DEC は
DD:MM:SS.SS）で指定できます。Equinox は例えば J2000 や 2000.0 のように指定
できます。

.. note:: SPOT は「SOSS 表記」の CSV ファイルからもターゲットを読み込め
          ます。OPE ファイルからのターゲット読み込みについては下記の
          セクションを参照してください。

プロットするターゲットに特定の色を設定したい場合は、ファイルを開く前に
「Color」ボタンをクリックして色を手動で選択します。そうしない場合、
ターゲットは後述の「Rotate target colors」というオプションに従って色付け
されます。

「File」ボタンを押して、上記の形式の CSV ファイルを探して選択します。
または、「File」ボタンの隣のボックスにファイルのパスを入力して「Set」を
押します（後者の方法は、編集したファイルを素早く再読み込みするのにも使え
ます）。

ターゲットが表に読み込まれるはずです。

OPE ファイルからのターゲット読み込み
=====================================
OPE ファイルは、すばる望遠鏡で使われる特別な形式のファイルです。この種の
ファイルのターゲットは「SOSS 表記」（RA は HHMMSS.SSS、DEC は +|-DDMMSS.SS、
Equinox は NNNN.0）で指定されます。

CSV ファイルの読み込みについての上記の手順に従い、代わりに OPE ファイルを
選択してください。

.. note::  この形式を読み込むには、オプションの「oscript」パッケージを
           インストールしておく必要があります
           （pip install git+https://github.com/naojsoft/oscript）。

PRM ファイルのアップロード
==========================
OPE ファイルは、しばしば別の「PRM」ファイルで定義されたターゲットを参照
します。CSV や OPE ファイルと同じ方法で ``.prm`` ファイルを選択（または
ドラッグ＆ドロップ）してください。ターゲットを読み込む代わりに、
``~/.spot/prm`` に保存（永続化）され、以後読み込む OPE ファイルが参照する
ターゲットを解決できるようになります。

表の情報
========
ターゲット表は、ターゲットに関する情報をまとめて表示します。ターゲット名、
RA、DEC といった静的な情報の列に加えて、方位角、高度、色分けされた出没
アイコン、時角、エアマス、大気分散、パララクティック角、月との離角といった
動的に更新される情報の列があります。

操作
====
ターゲットに「タグを付ける」には、リストで 1 つ以上のターゲットを選択して
「Tag」を押します。「Tagged」列の左側にチェックマークが表示され、どの
ターゲットにタグが付いているかが分かります。タグを解除するには、リストで
1 つ以上のタグ付きターゲットを選択して「Untag」を押します。

「<wsname>_TGTS」ウィンドウでは、SiteSelector プラグインで設定された時刻の
位置にターゲットがプロットされます。ターゲットにタグが付いている場合、色は
マゼンタ系になります。ターゲットが選択されている場合は青で表示され、名前は
「<wsname>_TGTS」ウィンドウ上で白い背景に赤い枠で表示されます。それ以外の
場合、ターゲットはファイルを読み込んだときに手動または自動で選択された色で
色付けされます。

「Select All」ボタンは表内のすべてのターゲットを選択します。

ターゲットを選択して「Delete」を押すと、選択したターゲットがリストから削除
されます。カテゴリの行だけが選択されている（ターゲットは選択されていない）
場合、このボタンを押すとそのカテゴリのすべてのターゲットが削除されます。

1 つのターゲットを選択して「Browse」をクリックすると、座標でターゲットを
調べて結果を Web ブラウザに表示するオプションのメニューが開きます。

「Plot:」の隣のドロップダウンメニューは、「<wsname>_TGTS」ウィンドウにどの
ターゲットをプロットするかを変更します。「All」を選ぶとすべてのターゲットが
表示され、「Uncollapsed」を選ぶと、表で折りたたまれて（隠されて）いない
ターゲットに加えてタグ付きおよび選択済みのターゲットが表示されます。
「Tagged+Selected」を選ぶとタグ付きまたは選択済みのすべてのターゲットが
表示され、「Selected」を選ぶと選択済みのターゲットのみが表示されます。

設定メニュー
============
「Settings」ボタンをクリックすると、いくつかの設定を有効にするためのポップ
アップメニューが表示されます。

* 「Merge Targets」をチェックすると、*それ以降*に読み込まれるすべての
  ターゲットが、ファイル名ごとにグループ化される代わりに「Targets」という
  単一の見出しの下にまとめられます。
* 「List Unreferenced Targets」は OPE ファイルにのみ影響する設定です。通常、
  Targets プラグインはコマンドで参照されていないターゲットを無視します。
  この設定をチェックすると、参照されているかどうかに関係なくすべての
  ターゲットが表示されます。PRM インクルードファイル内のターゲットを表示
  するのに使えます。
* 「Plot solar system objects」オプションをチェックすると、太陽、地球の月、
  惑星、冥王星が「<wsname>_TGTS」ウィンドウにプロットされます。

* 「Rotate target colors」オプションを有効にすると、読み込むファイルごとに
  自動的に選択された異なる色がターゲットに使われます（これは「Merge
  targets」がオフの場合にのみ有効になります）。
* 「Enable DateTime setting」は、CSV ファイルに「DateTime」列が含まれている
  場合に固定日時の設定を有効にするオプションです。有効にすると、表で 1 つの
  ターゲットを選択したときに、SiteSelector プラグインの日時がその日時に設定
  されます。この列の形式は YYYY-MM-DD HH:MM:SS <TZ> とします。タイムゾーン
  文字列を省略した場合は UTC とみなされます。

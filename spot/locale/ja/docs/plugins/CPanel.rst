CPanel
======
CPanel は SPOT アプリケーションのコントロールパネルです。

CPanel を使って新しいワークスペースを起動したり、特定のワークスペースで
SPOT の観測計画プラグインを開いたりします。

ワークスペースの作成
--------------------
ワークスペースを開くには、編集可能なドロップダウンボックス（``$HOME/.spot/
workspaces`` にあるワークスペースが一覧表示されます）から一つ選ぶか、新しい
名前を入力し、その右にある「Open Workspace」ボタンを押します。ワークスペース
名は一意でなければなりません。ボックスを空のままにすると、一般的な名前で
ワークスペースが作成されます。

開いたワークスペースのタブを選択すると、そこで開くプラグインを表示して
操作できます。

プラグインを起動するワークスペースの選択
----------------------------------------
「Select Workspace」ドロップダウンメニューで、SPOT の観測計画プラグインの
一つを起動したい、開いているワークスペースを選びます（そのワークスペースは
先に「Open Workspace」で開いておく必要があります）。次に、下のチェック
ボックスでプラグインを起動（チェック）または停止（チェック解除）します。

「SiteSelector」プラグインは、ワークスペース上の他の多くのプラグインの動作を
制御するため、ほとんどの場合起動しておくとよいでしょう。

ヒント: プラグインの最小化
--------------------------
プラグインの機能の一部を使いたいが、そのプラグインの UI 自体は見なくてよい
場合があります（「SiteSelector」「PolarSky」「SkyCam」プラグインなどが好例
です）。そのような場合は、プラグインを起動してから、プラグイン UI の
タイトルバーにある最小化ボタンをクリックしてプラグインを最小化し、他の
プラグインのためのスペースを空けられます。

.. important:: 一部のプラグインを閉じると、他のプラグインが期待どおりに
               動作しなくなることがあります。例えば SiteSelector プラグイン
               は、ほぼすべての他のプラグインへの時刻更新の供給元として重要
               で、完全に閉じてしまうと、そこの時刻トラッカーが他のプラグイン
               の更新を発火しなくなることがあります。迷った場合は、閉じる
               のではなくプラグインを最小化してください。

ワークスペースのレイアウトの保存
--------------------------------
「Save <wsname> layout」ボタンを押すと、そのワークスペースで開いている
プラグインウィンドウの現在のサイズと位置、および現在実行中のプラグインが
保存されます。各ワークスペースのレイアウトは、``$HOME/.spot/workspaces/
<wsname>/workspace.json`` に個別に保存されます。

次に SPOT を起動して同じ名前のワークスペースを開くと、保存されたサイズと
位置でウィンドウが再作成され、保存時に実行していたプラグインが再起動され
ます。

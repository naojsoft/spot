++++++++++++++++
Target Generator
++++++++++++++++

TargetGenerator を使うと、いくつかの方法でターゲットを動的に生成できます。
生成したターゲットは「Targets」プラグインの表に追加できます。

.. note:: このプラグインは「Targets」プラグインと組み合わせて使うため、
          「Targets」プラグインも開いておいてください。

方位角/高度からターゲットを生成する
====================================

「方位角:」ボックスに方位角を、「高度:」ボックスに高度を入力するだけです。
「ターゲット生成」をクリックすると、サイトに設定された時刻を使って AZ/EL 座標が
RA/DEC 座標に変換されます。これにより次のセクションの「赤経」「赤緯」「分点」
「名前」ボックスが入力されます。そこから次のセクションの説明に従って
ターゲットを追加できます。

既知の座標からターゲットを生成する
==================================

RA/DEC 座標が分かっている場合は、「赤経」「赤緯」「分点」「名前」と表示された
ボックスに入力できます。値は 60 進表記または度で指定できます。

.. note:: 「oscript」パッケージがインストールされていれば、「SOSS 表記」も
          使用できます。

「ターゲットを追加」をクリックしてターゲットを追加します。追加したターゲットは
「Targets」プラグインのターゲット表に表示されます。通常の方法でそこで選択
すると、「PolarSky」や「Visibility」のプロットに表示されます。

名前サーバーからターゲットを検索する
====================================

3 番目の領域のコントロールを使って、名前サーバー（NED または SIMBAD）経由で
ターゲットを検索できます。「サーバー」ボックスから名前サーバーを選び、「名前」
ボックスに名前を入力して「名前で検索」をクリックするだけです。天体が見つ
かると、2 番目のセクションの「赤経」「赤緯」「分点」「名前」ボックスが入力
されます。そこから「ターゲットを追加」ボタンをクリックしてターゲットを追加できます。

SiteSelector
============
SiteSelector プラグインは、観測を計画している場所と、その場所での観測時刻を
選択するために使います。

このプラグインは、ワークスペース上の他の多くのプラグインの動作を制御する
ため、ほとんどの場合最初に起動しておくとよいでしょう。

観測地の設定
------------
「Site:」ドロップダウンメニューで観測地を選択します。あらかじめ定義された
サイトがいくつも用意されています。

独自の観測地の追加
------------------
希望する場所が用意されていない場合は、簡単に独自の観測地を追加できます。
SPOT のソースコードをチェックアウトしている場合は、.../spot/spot/config/ に
「sites.yml」というファイルがあります。このファイルを $HOME/.spot にコピー
し、編集して独自のサイトを追加してください。サイトのすべての項目（緯度、
経度、標高など）を必ず設定してください。spot を再起動すると、新しい観測地が
表示されるはずです。

観測時刻の設定
--------------
時刻は現在時刻または固定時刻に設定できます。現在時刻にするには、「Time
mode:」ドロップダウンメニューから「Now」を選びます。

固定時刻にするには「Fixed」を選びます。すると「Date time:」と「UTC offset
(min):」のコントロールが有効になります。最初のボックスに YYYY-MM-DD
HH:MM:SS の形式で日時を入力し、「Set」を押します。

既定では、固定時刻の UTC オフセットは観測地のタイムゾーンのものに設定され
ますが、もう一方のボックスに UTC からの独自のオフセット（*分*単位）を入力
して「Set」を押すと、時刻を解釈するための特別なオフセットを指定できます。

.. note:: これは観測地のタイムゾーンを変更するものではありません。設定して
          いる固定時刻の解釈を設定するだけです。

プラグインの更新
----------------
観測地または時刻を変更すると、他のプラグインは（サイトと時刻の変更を購読
していれば。ほとんどのプラグインはそのように設計されています）自動的に更新
されます。

.. important:: このプラグインを閉じると、他のプラグインが期待どおりに動作
               しなくなることがあります。SiteSelector は、ほぼすべての他の
               プラグインへの時刻更新の供給元として重要で、完全に閉じて
               しまうと、そこの時刻トラッカーが他のプラグインの更新を発火
               しなくなります。迷った場合は、閉じるのではなく起動して最小化
               してください。

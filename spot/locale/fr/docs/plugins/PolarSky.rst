PolarSky
========
PolarSky dessine un tracé polaire dans la fenêtre « <wsname>_TGTS », se charge
d'y tracer les objets et affiche également une petite fenêtre présentant des
informations d'almanach astronomique (coucher/lever du Soleil, coucher/lever
de la Lune, crépuscules, etc.).

Comme les repères du tracé polaire sont utiles pour interpréter les tracés
des cibles, etc., vous voudrez généralement démarrer ce module si vous
prévoyez d'utiliser aussi les modules ``Targets`` ou ``Visibility``. Si les
informations d'almanach ne vous intéressent pas, vous pouvez réduire
l'interface du module après l'avoir démarré.
